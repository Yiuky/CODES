# Política de segurança

São scripts locais que leem e gravam metadados EXIF de imagens do próprio usuário; não abrem conexões de rede.

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use o recurso
[*Report a vulnerability*](https://github.com/Yiuky/CODES/security/advisories/new) do GitHub (aba **Security** do
repositório), que cria um relato privado.

Inclua o script, a versão do Python e, se possível, um exemplo mínimo que reproduza o problema (sem fotos que
contenham dados pessoais).
